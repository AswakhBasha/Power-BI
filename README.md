# Grocery Sales Performance Dashboard
This Power BI project visualizes sales performance data for Blinkit, an on-demand delivery app in India. The dashboard presents key metrics including total sales ($1.20M), average sales per order ($141), total items sold (8,523), and average customer rating (3.9). It breaks down performance by outlet size, location tier, item category, and fat content, offering insights into top-selling items (e.g., fruits, snacks, household products) and outlet trends from 2012 to 2022. It also compares outlet types such as grocery stores and various supermarket categories, highlighting differences in sales, ratings, and visibility. Filters allow dynamic analysis by outlet location, size, and item type for deeper business insights.
